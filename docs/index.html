Paper trading only — no orders are placed, no API keys are used. The autopilot runs on GitHub Actions every 5 minutes, evaluates the engines on closed bars, fills at the live price it sees and charges taker fee + spread + impact per side. This page re-reads docs/data/state.json every 60 s and re-marks open positions with live prices from Binance's public data API (data-api.binance.vision) directly in your browser. Signals use spot bars with the perp cost model; funding is not charged unless enabled in config. Walk-forward results are not a promise of future performance; this is not financial advice.
